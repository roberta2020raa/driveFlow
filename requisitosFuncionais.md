# DriveFlow — Requisitos Funcionais

## MVP

###  Usuário

**RF01 — Cadastro de usuário**  
O sistema deve permitir que o usuário realize seu cadastro.

**RF02 — Alteração de usuário**  
O sistema deve permitir que o usuário altere seus dados cadastrais.

**RF03 — Exclusão de usuário**  
O sistema deve permitir que o usuário exclua sua conta.

---

###  Veículo

**RF04 — Cadastro de veículo**  
O sistema deve permitir que o usuário cadastre seu veículo.

---

###  Aplicativos

**RF05 — Cadastro de aplicativos**  
O sistema deve permitir que o usuário cadastre os aplicativos utilizados para trabalhar.

**RF06 — Alteração de aplicativos**  
O sistema deve permitir que o usuário altere os dados dos aplicativos cadastrados.

**RF07 — Exclusão de aplicativos**  
O sistema deve permitir que o usuário exclua aplicativos cadastrados.

---

###  Ganhos e gastos

**RF08 — Cadastro de ganhos**  
O sistema deve permitir que o usuário registre seus ganhos.

**RF09 — Cadastro de gastos**  
O sistema deve permitir que o usuário registre seus gastos.

**RF10 — Visualização de gastos**  
O sistema deve permitir que o usuário visualize seus gastos registrados.

**RF11 — Visualização de ganhos**  
O sistema deve permitir que o usuário visualize seus ganhos registrados.

**RF12 — Visualização do balanço financeiro**  
O sistema deve permitir que o usuário visualize seu balanço financeiro, considerando seus ganhos e gastos registrados.
